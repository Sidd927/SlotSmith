# Feature capability matrix

Traced from the code on 11 Oct 2026 (branch of `slotsmith-vit-apex-presentation-e9e650`, backend `src/slotsmith/` unchanged). Status: **Implemented** (works end to end and was exercised in a browser), **Partial**, **Illustrative** (computed from the real engine but not user data), **Unsupported** (not in the product, not shown in the UI except as a stated limitation).
"Tests" refers to `tests/test_core.py` + `tests/test_audit_regressions.py` (backend), `tests/test_ui_core.py` (UI logic), `tests/test_ui_components.py`, `tests/test_ui_app.py` (journeys). "Browser" = verified in a real Chromium session on 11 Oct 2026.
